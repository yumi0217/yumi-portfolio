ミーティング背景画像作成Webアプリ

work
案件
業務委託案件
制作期間
2026年6月〜約3週間
制作工数
約30時間
概要
オンラインミーティングで使用する背景画像を、 ブラウザ上で簡単に作成・ダウンロードできるWebアプリ。 役職・漢字名・ひらがな名を入力すると、 リアルタイムで背景画像をプレビューでき、 完成した画像をPNG形式でダウンロードできます。
担当
要件定義・要件定義書作成、設計、実装、 動作確認・調整、納品まで一貫して担当
主な機能
  • 入力内容のリアルタイムプレビュー
  • 役職・漢字名・ひらがな名の入力
  • 必須入力チェック
  • PNG画像ダウンロード
  • 2560 × 1440pxでの画像出力
  • レスポンシブ対応
使用技術
  • HTML5
  • CSS3
  • JavaScript
  • Canvas API
  • html2canvas
